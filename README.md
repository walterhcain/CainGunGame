# CainGunGame
Simple Gun Game mechanic for Unturned. Different levels able to be set up. Best used on smaller map sizes.

## How it works 
17 levels are set up in the config. Guns and ammo type need to match. On death by melee, players move down levels. On kills, players move up levels. When a player reaches the winning score, game ends. Stats are given in the chat and the gun game resets.
